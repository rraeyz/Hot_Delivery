# Tip Over (çalışma adı: Hot Delivery)

Berbat bir scooter'la, arkadaki yemek kulesini devirmeden ve soğutmadan teslim etmeye çalıştığın fizik komedisi.

- Plan: [PLAN.md](PLAN.md) · İlerleme: [PROGRESS.md](PROGRESS.md) · Lisanslar: [CREDITS.md](CREDITS.md)

## Oyunu çalıştırma (Windows)
1. Godot 4.6 (veya daha yeni 4.x) indir: https://godotengine.org/download — "Godot Engine" (standart, .NET olmayan).
2. Bu repoyu indir: GitHub sayfasında yeşil **Code** düğmesi > **Download ZIP**, sonra zip'i bir klasöre çıkar.
3. Godot'u aç > **Import** > çıkardığın klasördeki `project.godot` dosyasını seç > **Import & Edit**.
4. Sağ üstteki ▶ (Play) düğmesine bas veya **F5**.

## Testler
